Installation
============

Utilisation de l'IA
-------------------

Le code présent dans ce projet a été rédigé à **99,9 %** par des élèves de NSI, en chair et en os. Cependant, l'erreur étant humaine, la solution à tous nos problèmes n'est pas toujours aussi évidente qu'on le souhaiterait.

.. important::
   Aucun segment de code n'a été généré à 100 % par une intelligence artificielle.

Toutefois, certaines parties ont été modifiées ou reformulées à l'aide d'outils d'IA pour :

* **Résoudre des bugs** complexes ;
* **Optimiser** certaines fonctions critiques.

La principale intervention de l'IA se situe dans le **moteur logique du jeu**. Cette utilisation a permis une optimisation du code, permettant ainsi une augmentation des performances générales du jeu.
